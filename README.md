# 🎵 Melo-Fine — High-Fidelity Glassmorphic Music Player

Melo-Fine is a Spotify-inspired music streaming application crafted with **Spring Boot 3 (Java 17)**, **PostgreSQL 18**, and **React 18 + Tailwind CSS**.

---

## ✨ Features

- **💎 Ultra-Modern Glassmorphism UI**: Ambient neon backdrops, translucent frosted-glass panels (`backdrop-blur-2xl`), and interactive 3D song cards with live equalizer animations.
- **🔐 Secure BCrypt Encryption**:
  - All user passwords are encrypted using **BCrypt**.
  - All OTP verification codes are **BCrypt-hashed** in the PostgreSQL `otp_verifications` table before validation.
- **📧 Dual Email System (Gmail SMTP)**:
  - **New User Signup**: Sends an aesthetic dark-mode glassmorphic HTML email with a 6-digit OTP code (5-minute expiry).
  - **User Sign-In**: Sends a personalized welcome-back greeting email asynchronously from `rannavin72@gmail.com`.
- **⚡ Smart Quota Caching**:
  - Searches check PostgreSQL first to conserve YouTube API quota.
  - On new queries, fetches video metadata via YouTube Data API v3 and caches songs in the database.
- **🎧 Spotify Bottom Player Bar**:
  - Play, pause, skip, seek scrubber, volume control, and shuffle controls powered by a hidden YouTube IFrame audio engine.

## 🚀 How to Run

### Option 1: One-Click Launcher (Recommended)
Double-click:
```bat
run-melofine.bat
```

### Option 2: Run Manually

#### 1. Start the Spring Boot Backend
```powershell
cd backend
mvn spring-boot:run
```
*Backend runs on: `http://localhost:8080`*

#### 2. Start the React Frontend
```powershell
cd frontend
npm run dev
```
*Frontend runs on: `http://localhost:5173`*

## 🗄️ Database Details
- **DBMS**: PostgreSQL 18
- **Database Name**: `Melo-Fine`
- **Tables automatically generated by Hibernate**:
  - `users`
  - `otp_verifications`
  - `songs`
